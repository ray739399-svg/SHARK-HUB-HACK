# SHARK HUB

Framework de desenvolvimento e testes para experiências próprias no Roblox.

## Recursos

- Interface gamer azul neon.
- Compatibilidade com controles por toque.
- Módulo de depuração visual.
- Calibração de câmera.
- Laboratório de física para bonecos de treinamento.
- Controlador de voo para ambientes privados.
- Organização modular em Luau.

## Estrutura

```text
SHARK-HUB/
├── README.md
└── src/
    ├── SharkHubClient.client.lua
    └── Modules/
        ├── DebugESP.lua
        ├── CameraCalibration.lua
        ├── PhysicsLab.lua
        └── FlightController.lua
```

## Instalação

1. Abra sua experiência no Roblox Studio.
2. Crie os scripts e módulos na hierarquia apropriada.
3. Copie o conteúdo de cada arquivo para o objeto correspondente.
4. Teste usando o modo Play em uma experiência privada.

## Segurança

Os testes físicos devem ser restritos a bonecos autorizados.
Ações sensíveis devem ser validadas pelo servidor.
Não utilize este projeto para interferir em experiências
de terceiros sem autorização.
